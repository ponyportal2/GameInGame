# Windows source-checkout launcher

`GameSmith.exe` in the repository root is a deliberately tiny x86-64 Windows GUI launcher generated by `build.py`.

It sets its working directory to the directory containing the executable and starts the root `launch-gamesmith.ps1`. The PowerShell script then:

1. uses `runtime/Godot_v4.7.2-stable_win64.exe` immediately when that file exists;
2. downloads the official Godot 4.7.2 x64 ZIP **only when that executable is missing**;
3. verifies the ZIP SHA-256 before extraction;
4. launches this repository's `project.godot` directly.

The Godot runtime itself is intentionally not tracked in Git: the GUI executable is about 180 MB, which is above GitHub's normal 100 MB per-file Git limit. Put it at `runtime/Godot_v4.7.2-stable_win64.exe` to make the checkout entirely offline after cloning.

Rebuild/verify the root launcher deterministically:

```bash
python3 tools/windows-repo-launcher/build.py GameSmith.exe
python3 tools/windows-repo-launcher/build.py --verify GameSmith.exe
```

The more featureful Go bootstrapper under `tools/windows-bootstrap/` remains the release-package launcher and carries the network/checksum unit tests. The root launcher keeps source checkouts small and makes GitHub the canonical project distribution.
